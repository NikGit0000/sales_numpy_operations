1.Create the project
2.Install NumPy into the project virtual environment
pip install numpy
3.Save installed packages to requirements.txt
pip freeze > requirements.txt
4.Run the main script
python main.py
5.Install all packages from requirements.txt (for another machine)
pip install -r requirements.txt
6.Git/GitHub
git init
git add .
git commit -m "NumPy vector operations homework"
git branch -M main
git remote add origin https://github.com/<your-username>/sales_numpy_operations.git
git push -u origin main
